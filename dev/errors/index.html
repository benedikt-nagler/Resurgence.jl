Errors

Every invalid operation throws a typed error from the ResurgenceError hierarchy, each with an informative showerror. Structs are immutable and every operation returns a new object, so an error never leaves a half-mutated value behind.

Resurgence.DegeneratePade — Type
DegeneratePade(L, M)

Thrown when the Toeplitz system of the [L/M] Padé approximant is singular — the underlying function admits a lower-degree rational representation. Request a lower order, or pass reduce = true to pade for automatic degree reduction.

source
Resurgence.IncompatibleSeries — Type
IncompatibleSeries(field, lhs, rhs)

Thrown by series arithmetic when the two operands disagree in field (e.g. :var, or a :power_offset mismatch that is not an integer shift).

source
Resurgence.InvalidArgument — Type
InvalidArgument(msg)

Generic escape hatch for invalid inputs not covered by a more specific error type.

source
Resurgence.NoSingularityFound — Type
NoSingularityFound(msg)

Thrown when a Borel-plane singularity is required but none could be detected — e.g. conformal_borel or subtract_singularity on a series whose Padé approximant has no poles. Pass the singularity position explicitly.

source
Resurgence.PoleOnRay — Type
PoleOnRay(pole, theta)

Thrown by Laplace summation when a Borel-plane pole lies (within tolerance) on the integration ray at angle theta — a Stokes ray. Use lateral_sum with side = :plus or :minus to integrate around it.

source
Resurgence.ResurgenceError — Type
ResurgenceError

Abstract supertype of all typed errors thrown by Resurgence.jl.

source
Resurgence.TransseriesSolveError — Type
TransseriesSolveError(msg)

Thrown by transseries_solve and the Painlevé I layer when a transseries ODE cannot be solved as posed: an action that fails the ODE's leading-balance equation, a resonant sector whose kernel was not supplied (lattice = …), or a required mixed-charge Stokes datum the model must provide.
