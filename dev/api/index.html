AbstractSeries

Abstract supertype of all series-like objects in Resurgence.jl (FormalSeries, BorelSeries).

Resurgence.FormalSeries — Type
FormalSeries{T} <: AbstractSeries

A truncated formal power series $x^{β_0} \sum_{n=0}^{N} a_n x^n$ in the variable var (default :ħ), with coefficients coeffs::Vector{T} (so coeffs[k] is $a_{k-1}$) and rational leading power power_offset $= β_0$.

The coefficient type T is fully generic: exact rationals, BigFloats, complex numbers, and ring elements from computer-algebra systems all work.

Examples

Φ = FormalSeries([1//1, 1, 2, 6], :ħ)            # Σ n! ħ^n, 4 terms
Φ = FormalSeries([1.0, 1.0], :x; power_offset = 1//2)   # √x (1 + x)
Φ[2]                                              # coefficient a₂ == 2

Resurgence.derivative — Method
derivative(Φ::FormalSeries) -> FormalSeries

The termwise derivative $∂_x$: $x^{β_0} \sum a_n x^n \mapsto x^{β_0 - 1} \sum (β_0 + n) a_n x^n$. Exact in the coefficient type whenever the powers are integral. Fractional powers use the corresponding coefficient arithmetic.

Resurgence.FormalSeries — Method
FormalSeries(name::Symbol, n; var = :ħ)

Construct n exact rational coefficients of a retained reference series. Names: :euler, :airy, :airy_bi, :quartic, :phi4, :exp. Euler uses power offset 1 and Borel function -1/(1+zeta). Airy uses hbar = z^(-3/2). Quartic uses H = p^2/2 + x^2/2 + gx^4. Phi4 is the formal expansion of the normalized integral of exp(-x^2/2-gx^4). These constructors supply coefficients, not transseries or physical Stokes data.

Resurgence.BorelSeries — Type
BorelSeries{T} <: AbstractSeries

The Borel transform of a FormalSeries, as a distinct type so that a double Borel transform is a type error. Fields:

  • series::FormalSeries{T} - the ζ-plane series $ζ^{β-1} Σ b_n ζ^n$ with the reduced coefficients $b_n = a_n / (β)_n$ (rising factorial $(β)_n = β(β+1)⋯(β+n-1)$). The true Borel transform is 1/Γ(β) times this; that constant is applied inside laplace_sum.
  • beta::Rational{Int} - the leading ħ-power $β$ of the source series.
  • constant_term::T - the $ħ^0$ coefficient of the source (a constant does not Borel-transform; it is split off here and re-added by summation).
  • source_var::Symbol - the variable of the source series (restored by inverse_borel).
source
Resurgence.borel — Method
borel(Φ::FormalSeries; beta = power_offset(Φ), var = :ζ) -> BorelSeries

Exact Borel transform of $Φ = ħ^β Σ a_n ħ^n$:

\[\mathcal{B}[Φ](ζ) = \sum_n \frac{a_n}{Γ(n+β)} ζ^{n+β-1} = \frac{ζ^{β-1}}{Γ(β)} \sum_n \frac{a_n}{(β)_n} ζ^n .\]

Requires beta ≥ 0. For beta == 0 the constant term $a_0$ is split off into the constant_term field and the rest is transformed with effective $β = 1$; the inverse and the Laplace sum restore it. The transform is exact in every coefficient type: inverse_borel(borel(Φ)) == Φ holds coefficient-by-coefficient.

source
Resurgence.inverse_borel — Method
inverse_borel(B::BorelSeries) -> FormalSeries

Exact inverse of borel: multiplies the reduced coefficients back by the rising factorials and restores the source variable, power offset, and any split-off constant term. inverse_borel(borel(Φ)) == Φ in every coefficient type.

Resurgence.AbstractBorelApproximant — Type
AbstractBorelApproximant

Abstract supertype of approximants of the reduced Borel function $Σ b_n ζ^n$ (the $ζ^{β-1}/Γ(β)$ factor stays with laplace_sum). The interface a subtype must provide:

  • callable at complex $ζ$: a(ζ) evaluates the approximant,
  • poles(a; refine = true) returning the physical-sheet singularities as a Vector{Complex{BigFloat}} sorted by absolute value.

Any such approximant plugs into the Laplace pipeline via laplace_sum(B, a, ħ) / lateral_sum(B, a, ħ). Subtypes: PadeApproximant, ConformalPade, and the AAAApproximant of the BaryRational package extension.

source
Resurgence.PadeApproximant — Type
PadeApproximant{T}

The rational function $[L/M](z) = p(z)/q(z)$ with $\deg p = L$, $\deg q = M$, $q(0) = 1$, matching a power series through order $z^{L+M}$. Callable: r(z) evaluates $p(z)/q(z)$ by Horner. Fields p, q hold ascending coefficients; var names the variable.

Resurgence.pade — Method
pade(B::BorelSeries; order = nothing, reduce = false) -> PadeApproximant

Padé approximant of the reduced Borel function $Σ b_n ζ^n$ (the stored coefficients; the overall $ζ^{β-1}/Γ(β)$ factor does not move the poles and is re-applied by laplace_sum). With order = m builds the diagonal $[m/m]$ approximant (needs $2m+1$ terms); by default uses all available terms, near-diagonally: $M = ⌊N/2⌋$, $L = N - M$ for $N = n\_terms - 1$. reduce = true degrades a degenerate request gracefully (see pade).

source
Resurgence.pade — Method
pade(c::AbstractVector, L, M; var = :ζ, reduce = false) -> PadeApproximant
pade(Φ::FormalSeries, L, M; reduce = false) -> PadeApproximant

The $[L/M]$ Padé approximant of the series with coefficients c (needs L + M + 1 of them; on a FormalSeries the polynomial part $Σ a_n x^n$ is used, ignoring the power offset). Works over any field; throws DegeneratePade when the Toeplitz system is singular. With reduce = true a singular system is instead retried at $[L-1/M-1]$ (walking down the degeneracy block, by Baker's block theorem, until the system is regular or $M = 0$) - the reduced approximant still matches the series through the originally requested order when the degeneracy is exact.

source
Resurgence.poles — Method
poles(r::PadeApproximant; refine = true) -> Vector{Complex}

Locate denominator zeros, sorted by modulus. Linear and quadratic denominators use BigFloat formulas. Higher degrees use Float64 companion seeds and optional BigFloat Newton refinement. Closely spaced or ill-conditioned higher-degree roots need independent checks. A small polynomial residual does not certify root locations or multiplicities.

Resurgence.laplace_sum — Method
laplace_sum(B::BorelSeries, ħ; θ = 0, order = nothing, rtol = eps^(3/4),
            check_poles = true) -> Complex

Laplace integral of the Borel transform along the ray $\arg ζ = θ$:

\[φ(ħ) = a_0 + \frac{1}{Γ(β)} \int_0^{∞ e^{iθ}} e^{-ζ/ħ}\, ζ^{β-1}\, r(ζ)\, dζ ,\]

where $r$ is the Padé approximant of the reduced Borel function (order is passed to pade) and $a_0$ the split-off constant term. The result's precision follows the type of ħ (pass a BigFloat for high precision). Throws PoleOnRay when a Padé pole lies on the integration ray - a Stokes ray; use lateral_sum there. Requires $\Re(e^{iθ}/ħ) > 0$ for convergence.

laplace_sum(B::BorelSeries, r::AbstractBorelApproximant, ħ; θ = 0,
            rtol = eps^(3/4), check_poles = true) -> Complex

The same integral with an explicit (possibly prebuilt or non-Padé) approximant r of the reduced Borel function - the seam every AbstractBorelApproximant plugs into, e.g. laplace_sum(B, conformal_borel(B), ħ).

source
Resurgence.lateral_sum — Method
lateral_sum(B::BorelSeries, ħ; θ = 0, side = :plus, tilt = 1//100,
            order = nothing, rtol = eps^(3/4)) -> Complex

Lateral Borel sum on a Stokes ray: integrates along the tilted ray $θ ± \mathrm{tilt}$ (side = :plus above, :minus below). Because the Padé approximant is meromorphic, the value is independent of tilt as long as no pole lies between the tilted ray and $θ$. Known singularities in that sector are refused. The quadrature sums the approximant, not a certified continuation of the original series. The lateral_sum(B, r::AbstractBorelApproximant, ħ; …) method takes an explicit approximant, like laplace_sum.

Resurgence.stokes_discontinuity — Method
stokes_discontinuity(B::BorelSeries, ħ; θ = 0, kwargs...) -> Complex

The Stokes discontinuity across the ray $\arg ζ = θ$: $\mathrm{disc}_θ = s_θ^+(ħ) - s_θ^-(ħ)$, the difference of the two lateral_sums. Sign convention (pinned by the Euler oracle test): for $Φ = Σ_n n!\,ħ^{n+1}$ (Borel pole at $ζ = 1$) and real $ħ > 0$, stokes_discontinuity(borel(Φ), ħ) ≈ +2πi\, e^{-1/ħ}.
