Borel plane

borel and inverse_borel are exact, in rising-factorial normalization. What you do next is approximate the Borel function from its Taylor coefficients: Padé is the default, ConformalPade handles a cut rather than isolated poles, and aaa_borel (see Plotting for the extension) is the AAA alternative. All of them are AbstractBorelApproximants and plug into the same summation routines.

Resurgence.BorelSeries — Type
BorelSeries{T} <: AbstractSeries

The Borel transform of a FormalSeries, as a distinct type so that a double Borel transform is a type error. Fields:

  • series::FormalSeries{T} — the ζ-plane series $ζ^{β-1} Σ b_n ζ^n$ with the reduced coefficients $b_n = a_n / (β)_n$ (rising factorial $(β)_n = β(β+1)⋯(β+n-1)$). The true Borel transform is 1/Γ(β) times this; that constant is applied inside laplace_sum.
  • beta::Rational{Int} — the leading ħ-power $β$ of the source series.
  • constant_term::T — the $ħ^0$ coefficient of the source (a constant does not Borel-transform; it is split off here and re-added by summation).
  • source_var::Symbol — the variable of the source series (restored by inverse_borel).
source
Resurgence.borel — Method
borel(Φ::FormalSeries; beta = power_offset(Φ), var = :ζ) -> BorelSeries

Exact Borel transform of $Φ = ħ^β Σ a_n ħ^n$:

\[\mathcal{B}[Φ](ζ) = \sum_n \frac{a_n}{Γ(n+β)} ζ^{n+β-1} = \frac{ζ^{β-1}}{Γ(β)} \sum_n \frac{a_n}{(β)_n} ζ^n .\]

Requires beta ≥ 0. For beta == 0 the constant term $a_0$ is split off into the constant_term field and the rest is transformed with effective $β = 1$; the inverse and the Laplace sum restore it. The transform is exact in every coefficient type: inverse_borel(borel(Φ)) == Φ holds coefficient-by-coefficient.

source
Resurgence.inverse_borel — Method
inverse_borel(B::BorelSeries) -> FormalSeries

Exact inverse of borel: multiplies the reduced coefficients back by the rising factorials and restores the source variable, power offset, and any split-off constant term. inverse_borel(borel(Φ)) == Φ in every coefficient type.

Padé approximants

Padé over any field, with pole and residue extraction. borel_pade_poles locates the Borel singularities of a series — the practical route from coefficients to the actions $A$ (instanton actions, in the physics vocabulary).

Resurgence.AbstractBorelApproximant — Type
AbstractBorelApproximant

Abstract supertype of approximants of the reduced Borel function $Σ b_n ζ^n$ (the $ζ^{β-1}/Γ(β)$ factor stays with laplace_sum). The interface a subtype must provide:

  • callable at complex $ζ$: a(ζ) evaluates the approximant,
  • poles(a; refine = true) returning the physical-sheet singularities as a Vector{Complex{BigFloat}} sorted by absolute value.

Any such approximant plugs into the Laplace pipeline via laplace_sum(B, a, ħ) / lateral_sum(B, a, ħ). Subtypes: PadeApproximant, ConformalPade, and the AAAApproximant of the BaryRational package extension.

source
Resurgence.PadeApproximant — Type
PadeApproximant{T}

The rational function $[L/M](z) = p(z)/q(z)$ with $\deg p = L$, $\deg q = M$, $q(0) = 1$, matching a power series through order $z^{L+M}$. Callable: r(z) evaluates $p(z)/q(z)$ by Horner. Fields p, q hold ascending coefficients; var names the variable.

source

borel_pade_poles(Φ::FormalSeries; beta = power_offset(Φ), order = nothing,

The one-liner: Borel transform, Padé approximation, pole extraction — the Padé estimate of the Borel-plane singularities of Φ.

Resurgence.pade — Method
pade(B::BorelSeries; order = nothing, reduce = false) -> PadeApproximant

Padé approximant of the reduced Borel function $Σ b_n ζ^n$ (the stored coefficients; the overall $ζ^{β-1}/Γ(β)$ factor does not move the poles and is re-applied by laplace_sum). With order = m builds the diagonal $[m/m]$ approximant (needs $2m+1$ terms); by default uses all available terms, near-diagonally: $M = ⌊N/2⌋$, $L = N - M$ for $N = n\_terms - 1$. reduce = true degrades a degenerate request gracefully (see pade).

source
Resurgence.pade — Method
pade(c::AbstractVector, L, M; var = :ζ, reduce = false) -> PadeApproximant
pade(Φ::FormalSeries, L, M; reduce = false) -> PadeApproximant

The $[L/M]$ Padé approximant of the series with coefficients c (needs L + M + 1 of them; on a FormalSeries the polynomial part $Σ a_n x^n$ is used, ignoring the power offset). Works over any field; throws DegeneratePade when the Toeplitz system is singular. With reduce = true a singular system is instead retried at $[L-1/M-1]$ (walking down the degeneracy block, by Baker's block theorem, until the system is regular or $M = 0$) — the reduced approximant still matches the series through the originally requested order when the degeneracy is exact.

source
Resurgence.poles — Method
poles(r::PadeApproximant; refine = true) -> Vector{Complex}

Zeros of the denominator $q$: located via the companion-matrix eigenvalues in ComplexF64, then (with refine = true) polished by Newton iteration in Complex{BigFloat}. Sorted by absolute value — for a Borel–Padé approximant the smallest is the leading Borel singularity.

source
Resurgence.residues — Method
residues(r::PadeApproximant; refine = true) -> Vector{Pair}

Pairs ζ₀ => p(ζ₀)/q′(ζ₀) for each simple pole of r, in the order of poles. This is the data alien derivatives consume (M2).

Conformal maps

For series whose Borel singularities form a cut rather than isolated poles, where Padé struggles.

Resurgence.ConformalMap — Type
ConformalMap{T}

The conformal map of the ζ-plane cut along $\{t\,ζ_0 : t ≥ 1\}$ (and, with pair = true, also along $\{-t\,ζ_0 : t ≥ 1\}$) onto the unit w-disk, with $0 ↦ 0$ and the branch point(s) mapped to $|w| = 1$:

  • single cut: $w(ζ) = \dfrac{1 - \sqrt{1 - ζ/ζ_0}}{1 + \sqrt{1 - ζ/ζ_0}}$, inverse $ζ(w) = 4ζ_0\, w/(1+w)^2$;
  • symmetric pair ($±ζ_0$): $w(ζ) = (1 - \sqrt{1 - ζ^2/ζ_0^2})\,ζ_0/ζ$, inverse $ζ(w) = 2ζ_0\, w/(1+w^2)$.

Non-symmetric singularity pairs at arbitrary angles are out of scope — use the AAA extension or the multi-saddle large_order_fit in that regime. Callable: m(ζ) evaluates the forward map (in complex arithmetic); inverse maps back. Construct with conformal_map or via conformal_borel.

source
Resurgence.ConformalPade — Type
ConformalPade{T} <: AbstractBorelApproximant

A conformally mapped Borel approximant: the reduced Borel series re-expanded in the map variable $w$ of a ConformalMap and approximated there by an inner PadeApproximant. Callable at ζ (c(ζ) = inner(w(ζ))); poles reports the branch point(s) plus the physical-sheet ($|w| < 1$) inner poles pulled back to the ζ-plane. Construct with conformal_borel; plugs into laplace_sum through the approximant seam.

source
Resurgence.conformal_borel — Method
conformal_borel(B::BorelSeries; zeta0 = nothing, pair = false, order = nothing,
                inner_order = nothing) -> ConformalPade

Build the conformally mapped approximant of the reduced Borel function of B: place the branch point at zeta0 (default: the smallest-modulus Borel–Padé pole, computed with pade(B; order, reduce = true); throws NoSingularityFound when there is none), re-expand the series in the map variable $w$ (exact for exact zeta0 and coefficients), and approximate in $w$: near-diagonally by default, inner_order = m for a diagonal $[m/m]$, and inner_order = 0 for the pure re-expanded polynomial (already convergent on the disk). Sum with laplace_sum(B, conformal_borel(B), ħ).

source
Resurgence.conformal_map — Method
conformal_map(zeta0; pair = false) -> ConformalMap

The ConformalMap placing the branch point at zeta0 (and, with pair = true, its mirror at -zeta0).

source
Resurgence.inverse — Method
inverse(m::ConformalMap, w) -> Number

The inverse map $w ↦ ζ$: $4ζ_0 w/(1+w)^2$ (single cut) or $2ζ_0 w/(1+w^2)$ (symmetric pair).
